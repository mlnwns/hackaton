# 원티드 스타일 디자인 규칙

아이폰 미러링에서 원티드 앱의 홈, 교육·이벤트, 소셜, 프로필, 전체 메뉴, 검색, 검색 결과, 채용 상세, 필터 바텀시트를 관찰해 정리한 규칙이다. 값은 화면을 보고 추정한 추천값이며 실제 원티드 내부 토큰이 아니다.

## 시각 원칙

1. 흰 화면과 또렷한 제목을 기본으로 삼는다.
2. 선과 그림자는 요소를 구분할 만큼만 쓴다.
3. 파란색은 선택 상태와 중요한 행동에만 쓴다.
4. 이미지와 제목은 분명하게, 부가 정보는 작은 회색 글자로 표시한다.
5. 둥근 모서리는 계층에 따라 6~28pt로 나누어 쓴다.
6. 반투명 재질은 떠 있는 내비게이션과 시트에 제한한다.

## 색상

| 역할 | 추천값 | 용도 |
|---|---:|---|
| Primary | `#3366FF` | 주요 버튼, 선택된 탭, 강조 링크 |
| Primary pressed | `#2B57E5` | 누른 상태 |
| Primary tint | `#EEF3FF` | 작은 선택 배경과 혜택 태그 |
| Text primary | `#17181A` | 제목과 본문 |
| Text secondary | `#5E626B` | 설명과 회사명 |
| Text tertiary | `#9398A3` | 날짜, 조건, 보조 아이콘 |
| Surface | `#FFFFFF` | 화면과 카드 |
| Surface subtle | `#F6F7F9` | 검색창, 비활성 칩 |
| Divider | `#ECEEF2` | 구분선과 카드 테두리 |
| Glass | `rgba(248,249,252,.76)` | 떠 있는 하단 탭 바 |
| Scrim | `rgba(17,24,39,.20)` | 바텀시트 뒤 화면 |
| Purple | `#8B5CF6` | 컬러 기능 아이콘 |
| Cyan | `#36C5E8` | 컬러 기능 아이콘 |
| Orange | `#FF8A2A` | 컬러 기능 아이콘 |
| Pink | `#F05BB5` | 컬러 기능 아이콘 |

한 화면에서 Primary가 가장 먼저 보이는 요소는 하나만 두는 편이 좋다. 사용자 브랜드의 주색이 따로 있으면 Primary에 그 색을 매핑하되, 나머지 중립색과 사용 범위는 유지한다.

## 글자

한글은 `Pretendard Variable`을 우선 사용하고 iOS 시스템 글꼴을 대체 글꼴로 둔다.

```css
font-family: "Pretendard Variable", Pretendard, -apple-system,
  BlinkMacSystemFont, "Apple SD Gothic Neo", sans-serif;
```

| 역할 | 크기/행간 | 굵기 | 자간 |

| 화면 제목 | 22/28 | 700 | -0.3 |
| 상세 제목 | 20/28 | 700 | -0.25 |
| 섹션 제목 | 18/24 | 700 | -0.2 |
| 카드 제목 | 14/20 | 600 | -0.1 |
| 본문 | 14/22 | 400 | 0 |
| 목록 라벨 | 13/18 | 500 | -0.05 |
| 부가 정보 | 12/17 | 400 | 0 |
| 캡션·탭 | 10/14 | 500 | 0 |

## 간격과 모서리

4pt 단위를 사용한다.

- 화면 좌우: 20pt, 상세 본문은 최대 24pt
- 같은 묶음 안: 8~16pt
- 섹션 사이: 28~32pt
- 큰 영역 사이: 40~48pt
- 칩 사이: 6~8pt
- 목록 행 안쪽: 좌우 16pt, 위아래 12~14pt
- 하단 탭 바가 있으면 콘텐츠 아래: 96~112pt

| 요소 | 반지름 |
|---|---:|
| 작은 칩과 배지 | 6pt |
| 버튼, 검색창, 이미지 | 8~10pt |
| 일반 카드와 배너 | 12pt |
| 큰 그룹 카드 | 14~16pt |
| 팝업 | 18~20pt |
| 바텀시트 상단 | 22~26pt |
| 떠 있는 하단 탭 바 | 28~30pt |

## 테두리와 그림자

- 일반 카드: `1px solid #ECEEF2`
- 칩: `1px solid #E7E9EE`
- 떠 있는 패널: `0 10px 30px rgba(17,24,39,.12)`
- 반투명 패널: `1px solid rgba(255,255,255,.55)`
- 일반 카드는 테두리와 그림자를 동시에 쓰지 않는다.
- 진한 검은 그림자, 진한 회색 외곽선, 여러 겹의 그림자를 피한다.

## 레이아웃

### 상단 바

- 상태 바를 제외한 높이 48~52pt, 좌우 20pt
- 왼쪽에 20~22pt 화면 제목, 오른쪽에 20~22pt 동작 아이콘
- 아이콘 사이 16~20pt
- 새 알림은 모서리의 4~5pt 파란 점으로 표시
- 스크롤하면 제목 바는 남고 프로모션과 빠른 메뉴는 사라짐
- 아래 경계는 진한 선 대신 약한 블러 또는 그림자로 처리

### 섹션

- 18pt 굵은 제목과 오른쪽의 12pt 회색 `전체보기`
- 제목과 카드 사이 14~16pt
- 섹션 사이 28~32pt

### 가로 카드 목록

- 다음 카드 일부를 노출해 가로 스크롤을 알린다.
- 카드 사이 12pt
- 이미지 4:3, 반지름 8~10pt, `cover`
- 제목 14pt/600, 최대 두 줄
- 회사명·경력·지역 11~12pt 회색
- 북마크는 이미지 오른쪽 위에 겹친다.

### 두 열 카드 목록

- 열 사이 12pt
- 카드 폭: `(화면 폭 - 좌우 여백 40 - 열 간격 12) / 2`
- 이미지 4:3 또는 정사각형에 가까운 비율
- 제목과 정보는 이미지 아래 흰 화면에 직접 놓는다.
- 카드마다 배경과 그림자를 만들지 않는다.

### 그룹 목록

- 흰 배경, 반지름 12~14pt
- 행 높이 44~48pt
- 왼쪽에 26~28pt 옅은 색 원과 14~16pt 아이콘
- 오른쪽에 14pt 회색 화살표
- 구분선은 텍스트 시작점부터 그리거나 생략

## 컴포넌트

### 빠른 메뉴

- 한 줄에 네 개, 같은 너비
- 컬러 아이콘 32~36pt, 라벨 11~12pt
- 아이콘과 라벨 사이 8pt
- 실제 터치 영역 최소 44×44pt

### 안내 배너

- 높이 48~56pt, 안쪽 좌우 14~16pt
- 반지름 10~12pt, 연한 보라색 테두리
- 왼쪽 28~32pt 일러스트, 오른쪽 12~13pt 굵은 설명

### 검색창

- 높이 36~40pt, 반지름 8~10pt
- 배경 `#F6F7F9`
- 16pt 돋보기, 13~14pt 입력 글자
- 검색 결과 화면에서는 왼쪽 뒤로가기와 오른쪽 취소 동작을 함께 둔다.

### 텍스트 탭

- 높이 40~44pt
- 활성 글자 13pt/600, 비활성 글자 13pt/400
- 활성 탭 아래 2pt 검은 선
- 탭 사이 20~24pt

### 필터 칩

- 높이 28~32pt, 좌우 안쪽 10~12pt
- 반지름 6~8pt, 1px 연한 테두리
- 글자 11~12pt/500, 앞 아이콘 12~14pt
- 선택 상태는 파란 테두리나 연한 파란 배경 중 하나만 사용
- 소셜의 주제 필터는 활성 칩에 검은 배경과 흰 글자를 사용

### 채용 상세

- 상단 이미지는 화면 폭을 채우고 페이지 수는 검은 반투명 배지로 표시
- 본문 좌우 20~24pt
- 포지션 제목 20pt/700, 회사 링크 12~13pt/600
- 섹션 제목 18pt/700, 본문 14~15pt에 행간 22~24pt
- 아래에 44pt 북마크 버튼과 44~48pt Primary 지원 버튼을 고정
- 고정 영역은 진한 선보다 약한 블러와 그림자로 구분

### 빈 상태와 스켈레톤

- 빈 상태는 작은 3색 기하학 도형, 짧은 제목, 한 줄 설명으로 구성
- 스켈레톤은 `#F1F2F4`에 가까운 낮은 대비 사용
- 쉬머는 1.2~1.6초로 느리고 약하게 반복

## 떠 있는 하단 탭 바

- 화면 좌우 16pt, 안전 영역 위 8pt
- 높이 60~64pt, 반지름 28~30pt
- 다섯 항목을 같은 너비로 나눔
- 아이콘 20~22pt, 라벨 9~10pt/500
- 활성 아이콘과 라벨은 Primary, 비활성은 `#7D828C`
- 배경 `rgba(248,249,252,.62~.78)`
- 블러 20~28pt, 채도 140~180%
- 위쪽 흰색 하이라이트와 넓고 약한 그림자
- 콘텐츠가 바 아래로 실제로 지나가야 함
- 활성 아이콘 뒤에 24~28pt의 매우 옅은 Primary 원을 둘 수 있음

불투명한 흰 영역 위에 반투명 바를 놓으면 이 효과가 사라진다. 블러는 반드시 실제 콘텐츠를 배경으로 받아야 한다.

## 필터 바텀시트

- 처음에는 화면 높이의 50~55%, 내용이 많으면 약 70%까지 확장
- 상단 반지름 22~26pt
- 손잡이 36×4pt, `#D9DCE2`
- 밝은 블러 또는 `rgba(255,255,255,.90)` 배경
- 뒤 화면은 `rgba(17,24,39,.18~.22)`로 어둡게 처리
- 필터 종류는 상단 텍스트 탭으로 표시
- 선택지는 28~30pt 높이의 칩으로 배치
- 아래에 40pt 초기화 버튼과 남은 폭을 채우는 44pt 적용 버튼
- 적용 버튼에 선택 수 표시: `2개 적용`

## 아이콘

세 종류를 구분한다.

### 내비게이션과 동작

- 24×24pt 캔버스, 실제 도형 20~22pt
- 선 굵기 1.75~2pt, 둥근 끝과 모서리
- 비활성 `#7D828C`, 활성 Primary
- 상태가 바뀌어도 같은 실루엣을 유지하고 색이나 작은 면만 바꿈

### 빠른 메뉴용 컬러 아이콘

- 투명 44×44pt 캔버스, 실제 도형 28~36pt
- 단순한 면 2~4개, 비슷한 계열의 색 2~3개
- 검은 외곽선 없음
- 겹치는 면에 20~35% 투명도
- 별, 점, 접힌 모서리 중 장식 하나만 사용
- 그림자는 생략하거나 `0 3 8 rgba(30,40,80,.10)`만 사용
- 별도의 흰색 둥근 사각형을 습관적으로 깔지 않음

아이콘 생성 프롬프트에 다음 조건을 넣을 수 있다.

```text
[기능]을 나타내는 모바일 앱용 컬러 아이콘. 44×44 투명 캔버스,
실제 도형 32pt, 단순한 면 3개 이하, 둥근 모서리,
검은 외곽선 없음, [주색]과 인접한 보조색 두 개,
겹치는 면에는 약한 투명도, 작은 장식은 하나만 사용.
작은 크기에서도 기능을 알아볼 수 있는 실루엣.
```

### 목록 행

- 26~28pt 옅은 색 원
- 안쪽 14~16pt 단색 아이콘
- 빠른 메뉴 아이콘보다 장식을 줄임

## 동작

- 버튼: 누를 때 `scale 1 → .97`, 80~100ms
- 놓을 때 `.97 → 1`, 140~180ms
- 탭 활성 상태: opacity와 scale, 160~200ms
- 일반 패널: 감쇠 1.0, 반응 시간 .32~.40초
- 드래그로 움직인 시트: 감쇠 .86~.92, 반응 시간 약 .35초
- 반투명 패널: opacity만 바꾸지 말고 blur와 scale `.98 → 1`을 함께 변경
- 패널은 들어온 방향으로 다시 나감
- 동작 중에도 사용자가 다시 만지면 즉시 새 입력을 따름
- 과장된 튕김은 플릭이나 드래그처럼 사용자가 속도를 만든 동작에만 허용

## 접근성

- 터치 영역 최소 44×44pt
- 선택 상태는 색과 함께 밑줄, 면, 굵기 중 하나로 표시
- 투명도 줄이기: 패널 배경을 `rgba(248,249,252,.96)` 이상으로 올리고 블러 제거
- 동작 줄이기: 이동과 확대 대신 120~160ms 페이드 사용
- 큰 글자 설정에서는 카드 높이를 고정하지 않음
- 아이콘 버튼에 접근성 이름을 제공

## 피해야 할 모습

- 모든 버튼과 카드를 큰 알약 모양으로 만드는 것
- 카드마다 진한 그림자를 넣는 것
- 화면 곳곳에 Primary 테두리를 쓰는 것
- 하단 바 아래를 흰색으로 비워 블러가 보이지 않는 것
- 블러 없이 투명도만 낮춰 뒤 글자가 그대로 보이는 것
- 시스템 아이콘과 컬러 기능 아이콘의 그림체를 섞는 것
- 작은 회색 글자를 지나치게 연하게 만드는 것
- 모든 화면 이동에 튕기는 스프링을 쓰는 것

## 검수표

- 화면 좌우 여백이 20~24pt로 일정한가?
- 제목, 카드 제목, 본문, 부가 정보가 구분되는가?
- Primary를 중요한 행동과 선택에만 썼는가?
- 이미지 카드의 반지름과 비율이 같은가?
- 하단 탭 바 뒤로 콘텐츠가 지나가는가?
- 마지막 콘텐츠가 하단 탭 바에 가려지지 않는가?
- 아이콘 종류별 그림 규칙을 지켰는가?
- 손가락이 닿은 뒤 100ms 안에 반응하는가?
- 접근성 설정에서도 글자와 조작 요소가 보이는가?
- 원티드 전용 브랜드 에셋을 복제하지 않았는가?
