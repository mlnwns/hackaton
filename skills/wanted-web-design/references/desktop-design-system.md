# 원티드 PC 웹 관찰 기반 디자인 시스템

## 근거와 범위

2026-10-30, 브라우저에서 원티드 PC 웹을 1440×900으로 살펴봤다. [홈](https://www.wanted.co.kr/), [채용 목록](https://www.wanted.co.kr/wdlist), [콘텐츠](https://www.wanted.co.kr/events), 채용 상세 화면을 관찰하고 목록의 경력 필터와 검색 오버레이를 열었다. 페이지와 기능은 바뀔 수 있다. 원티드의 실제 내부 설계 시스템 전체나 모든 상태를 확인한 것은 아니다.

일부 수치는 화면의 보이는 요소에 대한 브라우저 계산값이다. 나머지는 화면을 바탕으로 한 새 서비스용 추천값이다. 실제 내부 변수명·브레이크포인트·공식 디자인 명세로 표현하지 않는다.

파란색은 중요한 행동, 선택, 링크에 집중한다. 사용자가 명시한 브랜드 주색이 있으면 그 색을 사용하되 정보 위계와 절제된 사용 방식을 지킨다. 오류·위험은 색 하나만으로 전달하지 않는다.

## PC 레이아웃

- **상단 바:** 흰 배경, 좌측 브랜드 자리, 가로 메뉴, 우측 검색·계정·보조 행동. 관찰한 화면에서 메뉴 영역 높이는 약 60px. 사용자 제품에 필요한 항목만 둔다.
- **중앙 콘텐츠:** 화면 종류에 따라 폭이 다르다. 관찰한 1440px 화면에서 목록은 양쪽 약 70–80px 여백의 넓은 영역, 콘텐츠 페이지는 그보다 좁은 중앙 영역이었다. 고정값이 아닌 `max-width`와 유동 여백으로 구현한다.
- **섹션:** 진한 제목과 우측 보조 링크 또는 정렬 도구를 한 줄에 놓고 콘텐츠와 명확한 간격을 둔다. 페이지 전체가 카드 테두리로 둘러싸이지 않도록 한다.
- **탐색·목록:** 상단에 범위 선택과 정렬, 그 아래 작은 필터 칩을 두고 결과를 그리드 또는 행 목록으로 표시한다. 관찰한 PC 채용 목록은 4열 이미지 카드이며 카드 간 간격은 약 16px이었다. 주제에 맞는 데이터 표가 적합하면 표를 사용한다.
- **상세:** 제목과 메타 정보·본문을 넓은 주 영역에 두고, 주요 행동이나 요약은 오른쪽 보조 열에 둔다. 관찰한 상세는 콘텐츠와 별도 약 340px 행동 열로 구성됐다. 좁아지면 자연스럽게 한 열로 쌓는다.
- **콘텐츠:** 넓은 가로 배너와 그 아래 제목·카테고리·이미지 카드를 사용하는 화면도 있다. 업무 화면에 배너를 기계적으로 추가하지 않는다.

## 컴포넌트

- **기본 버튼:** 중요한 행동은 파란 채움과 흰 글자. 보조 행동은 흰 바탕의 얇은 테두리 또는 텍스트. 로딩·비활성·포커스 상태와 접근 가능한 이름을 제공한다.
- **필터 칩:** 작은 둥근 사각형, 옅은 경계, 짧은 라벨·선택 상태. 필터가 실제 결과를 바꾸고 초기화가 가능해야 한다.
- **선택 팝오버/대화상자:** 원티드 PC 경력 필터는 흰색 둥근 패널 안에 제목, 닫기, 범위 조절, 초기화와 파란 적용 버튼을 배치했다. 구현 시 키보드 조작·레이블·닫기·포커스 복귀를 포함한다.
- **검색:** 돋보기와 옅은 회색 입력 표면, 검색어·관련 결과를 읽기 쉬운 폭으로 제시한다. 검색과 결과가 연결되어야 하며 검색어가 없을 때와 결과가 없을 때를 구분한다.
- **이미지 카드:** 둥근 이미지 위에 선택적 작은 보조 동작, 아래에 제목→이름→보조 정보 순서를 둔다. 이미지 없이도 과제를 풀 수 있으면 중립 배경이나 간결한 도형을 쓰고 관련 없는 이미지는 넣지 않는다.
- **데이터 행/표:** 제품의 실제 항목명과 상태를 사용한다. 스캔 가능한 제목·보조 정보·상태·행동을 정렬하고, 정렬·필터·빈 상태가 필요할 때만 구현한다. 표는 행·열 머리글을 명확히 한다.
- **탭·세그먼트:** 선택된 항목을 배경·글자·접근성 상태로 구분한다. 데이터나 보이는 영역이 실제로 바뀌어야 한다.
- **상태:** 로딩·빈 결과·오류에 원인 또는 다음 행동을 짧게 적고, 확인되지 않은 수치·기능을 사실처럼 표시하지 않는다.

## 주제별 조합 예시

- **설비 관리:** 상단 바 + 핵심 현황 + 필터 + 설비 표/목록 + 선택 항목 상세. 이미지 카드나 지원 버튼은 불필요하다.
- **상품 탐색:** 상단 바 + 검색·필터 + 상품 카드 그리드 + 상품 상세·선택 행동.
- **문서·업무 관리:** 상단 바 + 상태 요약 + 검색·정렬 + 목록/표 + 생성·상세 패널.

예시는 기능 우선순위를 정하기 위한 조합이다. 과제의 실제 필수 조건이 우선이며, 위 항목을 전부 구현해야 한다는 뜻이 아니다.
